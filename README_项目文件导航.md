# 金箔非遗数字体验与活化传播项目文件导航

本目录是项目迁移后的正式工作根目录。开始新的 Codex 任务时，优先读取 `00_项目交接与总览`。

## 目录说明

- `00_项目交接与总览`：项目上下文、接续提示词、迁移校验清单；
- `01_项目简报与产品需求`：项目简报、PRD及历史版本；
- `02_团队任务与项目启动`：四岗位7周任务表和第1周启动包；
- `03_首次专业访谈`：访谈设计说明、原始准备清单和10份执行材料；
- `90_制作与校验脚本`：Word材料生成、修订和校验脚本，以及历史实施计划。

## 版本原则

- PRD V0.3是当前产品需求基线；
- PRD V0.1和原始V0.2仅用于追溯；
- 新文件继续升版，不直接覆盖历史版本；
- 未经专业确认的事实继续标记为“待核实”或“候选方案”。
