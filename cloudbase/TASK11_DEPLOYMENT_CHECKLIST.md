# P0 第 11 项部署与验收操作清单

> 范围：本清单用于专用 CloudBase 内测环境、小程序配置和真机验收。执行前请确认本地 `npm test` 已通过。本清单不授权公开发布或提交审核。

## 安全边界

- [ ] 仅使用一个新建的、只服务于本微信小程序的专用 CloudBase 内测环境。
- [ ] 不复用 Web、其他小程序或其他客户端的环境。
- [ ] 不启用 Web SDK、HTTP/API 网关、HTTP 函数、混合触发、定时触发器或数据库触发器。
- [ ] 不在仓库、截图、聊天记录或提交中写入真实 AppID、CloudBase 环境 ID、盐值、审批人 ID、OpenID、UnionID、手机号、邮箱或真实姓名。
- [ ] 五步制箔候选路线在专业审核前继续保持 `internal_placeholder` / `internal_approved`，不得公开发布。

## 1. 创建专用 CloudBase 环境

操作：在 CloudBase 控制台创建新的内测环境，并只关联目标微信小程序。

验收：

- [ ] 环境已关联目标小程序。
- [ ] 环境没有其他客户端入口、Web SDK 或额外触发器。
- [ ] 环境中只有本项目需要的三个普通云函数。

可回传的非敏感结果：环境已创建、已绑定目标小程序、无其他客户端或触发器；不要回传环境 ID。

## 2. 配置微信开发者工具

操作：

1. 从 `project.config.example.json` 复制本地 `project.config.json`，不要提交该文件。
2. 在微信开发者工具导入仓库根目录，确认小程序根目录为 `miniprogram/`、云函数根目录为 `cloudfunctions/`。
3. 仅在本地将 `miniprogram/config/runtime-config.js` 的 `cloudEnvId` 设为目标环境；不要提交真实值。

验收：

- [ ] 项目能够导入和编译。
- [ ] 云开发面板显示已连接目标环境。
- [ ] 无真实标识进入 Git 工作区或提交。

可回传的非敏感结果：是否成功导入、是否成功连接、编译错误文本或脱敏截图；不要回传 AppID 或环境 ID。

## 3. 创建集合并导入数据库规则

操作：仅创建以下四个集合，并导入 `database-rules/` 中同名 JSON：

1. `app_config`
2. `content_items`
3. `media_assets`
4. `behavior_events`

验收：

- [ ] 集合名恰好为上述四个，没有额外 analytics 或身份集合。
- [ ] `behavior_events` 的客户端 read/create/update/delete 均为 false。
- [ ] 其余三集合只允许 `trial` 与允许审核状态的读取。
- [ ] 所有客户端写入均关闭。

可回传的非敏感结果：四集合是否齐全、四项规则是否导入成功、是否存在额外集合。

## 4. 导入候选种子数据

操作：仅向已创建的专用内测环境按下列顺序导入：

1. `seed-data/app_config.json`
2. `seed-data/content_items.json`
3. `seed-data/media_assets.json`
4. `seed-data/behavior_events.json`

验收：

- [ ] `app_config` 中恰好有一条五步制箔候选路线。
- [ ] 该路线为 `internal_placeholder` / `internal_approved`。
- [ ] `content_items` 不含 `confirmedRoute`。
- [ ] `media_assets` 仍是本地候选占位路径，未经审核素材不得公开使用。
- [ ] `behavior_events` 为 0 条记录。

可回传的非敏感结果：四集合记录数、候选路线状态、事件集合记录数；不要回传记录全文。

## 5. 导入函数权限并部署云函数

操作：

1. 在环境级云函数权限中导入 `function-rules.json`。
2. 依次对以下目录使用“上传并部署：云端安装依赖”：
   - `cloudfunctions/bootstrapAnonymousId`
   - `cloudfunctions/confirmRoute`
   - `cloudfunctions/submitBehaviorEvent`
3. 不上传本地 `node_modules`，不启用 HTTP 函数。

验收：

- [ ] 权限规则默认拒绝，仅三个函数有显式调用规则。
- [ ] 三个函数均部署成功，依赖安装成功。
- [ ] 未启用 HTTP、网关、额外触发器或其他客户端调用入口。

可回传的非敏感结果：三个函数是否部署成功、部署日志中的错误文本、是否确认未启用 HTTP 或触发器。

## 6. 配置云函数环境变量

操作：

- [ ] 在三个函数中配置同一 `ANONYMIZATION_SALT`，去首尾空白后至少 32 字符。
- [ ] 在三个函数中配置目标小程序的 `WECHAT_APP_ID`。
- [ ] 仅在 `confirmRoute` 中配置非空、无重复的匿名 `APPROVER_IDS`。
- [ ] 不设置 `OPENID` 或 `UNIONID` 环境变量。

验收：

- [ ] 三个函数的前两项变量已配置且一致。
- [ ] `confirmRoute` 额外有审批人列表。
- [ ] 未将任何变量值写入仓库、JSON、README、截图或聊天记录。

可回传的非敏感结果：仅确认“变量已配置且格式检查通过”，不要发送变量名以外的值。

## 7. 开发者工具与真机流程验收

在模拟器和至少一台 iOS 或 Android 真机检查：

- [ ] 首页可进入唯一的五步制箔候选路线。
- [ ] 做捻子、装家生、打箔、出具检查、切箔成叶依序完成。
- [ ] 出具检查可返回打箔返工，并继续沿用同一份 `session.grid`。
- [ ] 提示、重试、退出和结果页操作正常。
- [ ] “再体验一次”回到该制箔路线。
- [ ] 候选免责声明持续可见。
- [ ] 页面不显示排名、证书或未经确认的工艺事实。
- [ ] 未部署云函数或断网时，体验不会被埋点失败阻断。

可回传的非敏感结果：模拟器与真机系统版本、每个检查项的通过/失败、失败时的错误文本或脱敏截图。

## 8. 云端安全与数据验收

操作与验收：

- [ ] 验证客户端无法直接写入 `behavior_events`。
- [ ] 完成一次候选体验，确认事件仅通过 `submitBehaviorEvent` 写入。
- [ ] 确认事件记录不含原始身份字段。
- [ ] 对同一 `eventId` 发送相同载荷，确认只写入一次。
- [ ] 对同一 `eventId` 发送不同载荷，确认被拒绝且不覆盖。
- [ ] 在独立测试后验证错误或缺失 AppID 会失败关闭，并立即恢复正确配置。

可回传的非敏感结果：每项通过/失败、事件记录数量变化、是否出现原始身份字段（应为“否”）；不要回传事件内容、事件 ID 或变量值。

## 9. 进入上传前的判定

仅当以下项目均满足，才可进入小程序上传和体验二维码阶段：

- [ ] 第 1 至第 8 节全部通过。
- [ ] 专业内容确认与素材授权已完成，或继续以明确候选内测状态运行且不提交公开审核。
- [ ] 已记录测试设备、已知问题、回退版本和验证日期。
- [ ] 未在仓库中发现任何真实标识、密钥或原始身份信息。

未满足任一项时：停止上传、二维码生成和公开审核，先修正对应问题。
