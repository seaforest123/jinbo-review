# 互动工艺画册 P0 设计

## 目标

在现有博物馆数字展候选原型上，以真机优先、离线可演示为标准，完成约三分钟的"材料—动作—结果"互动工艺画册体验，并在关键步骤配以本地候选帧动画增强沉浸感。P0 着重帮助用户理解候选工艺逻辑，并提供清晰的现场操作反馈。

## 范围与取舍

- 首版以候选 AI 生成的**帧序列动画**为主，不接入真实拍摄、视频文件或网络请求。
- 体验页是主要改造面；首页、档案和结果页只增加轻量的互动入口提示与完成标记。
- 仅使用单指点按和拖动；不使用录音、陀螺仪、多指手势或权限申请。
- 每条路线保持三步、总时长约三分钟，覆盖材料、动作、结果三类认知目标。
- 不新增 CloudBase 集合、云函数、权限、HTTP/API 网关、触发器、Web SDK、网络请求或身份字段。

## 候选帧动画与边界

- 2-3 个关键步骤各对应一组本地候选帧动画，每组 6-10 张连续候选图（WebP/PNG），按固定间隔（约 100-150ms/帧）循环切换，在前端表现为动态效果，本质上仍是静态图片资源的连续播放——**不生成、不导入任何视频文件**（.mp4/.webm/.mov 等一律不使用），也不使用 `<video>` 组件或任何视频编解码路径。
- 帧动画只表现抽象纸张层次、金色箔片纹理、非写实工具轮廓和操作方向，不可描述为真实工艺记录、正式授权素材或专业结论。
- 帧动画、静态图及相邻说明统一展示："候选视觉示意，尚待专业确认"。
- 任一帧加载失败即判定该动画不可用，整体回退为现有候选静态图，交互入口始终可用；不出现动画播放到一半卡住或空白的情况。

## 体验流程

### 第一步：材料

用户从 2-3 个抽象候选材料卡中点按与任务目标匹配的一项，材料卡旁可循环播放对应候选帧动画（如箔片质感的微动效果）。选择后显示"已选取候选材料"的展签反馈，并允许重新选择；点击继续后完成本步。

### 第二步：动作

用户在金色箔片候选画布上单指横向拖动，将箔片从起点铺至目标区域；画布上方可循环播放"铺贴"分解帧动画作为引导。连续进度条展示覆盖完成度，达到现有阈值自动完成。触控判定纯本地执行，不依赖动画帧率或播放状态。

### 第三步：结果

用户按画面提示连续点按节奏标记，完成抽象"锤打"反馈；节奏标记区可循环播放"锤打"分解帧动画作为节拍提示。每次有效点按推动可见节奏进度；误触仅提示重新按当前标记，不记录身份数据或新增云端埋点。完成后进入既有学习报告。

## 页面调整

- 首页和档案：保持候选图片展签结构，只加"含三步互动体验"的文字提示。
- 体验页：每步显示本地候选帧动画区域（`image` 组件 + JS 定时切帧，循环播放）；任一帧加载失败时显示静态图，始终展示步骤说明、互动区域、即时反馈、候选提示与既有提示/重试/退出能力。
- 结果页：保留非评分学习报告和图文回看；为本次完成的三步显示"已完成互动"的轻量标记。

## 架构与数据

- 新增纯数据模块，按步骤标识返回候选帧动画描述：帧路径数组、切帧间隔、候选提示。资源不存在或未生成时不渲染任何动态效果，改用现有静态图。
- 新增纯领域交互辅助模块：材料选择状态、铺贴拖动状态、锤打节奏状态。它不调用 wx、不读写存储，也不接触分析服务。
- 体验控制器保持既有状态机、学习会话、匿名分析事件契约和完成流程；仅暴露当前互动状态与页面事件方法。
- 页面层维护一个轻量定时器驱动帧序列播放，进入新步骤时重置到第一帧，退出/隐藏/重试时清除定时器，避免内存泄漏或后台空转。
- 不改变路线标识、步骤标识、学习报告结构或既有埋点名称。

## 容错、性能与隐私

- 静态图和帧动画资源错误均不能阻止开始、完成、提示、重试、退出或生成本地学习报告。
- 帧动画默认静音（本身无音轨）、不自动播放视频、不请求任何媒体或设备权限。
- 所有帧动画资源本地打包；实施前核对小程序包体限制（帧序列比单个视频文件更容易控制体积和分包），必要时置于独立分包，但不得改变离线能力。
- 不读取、显示、记录或传输真实 AppID、CloudBase 环境 ID、密钥、OpenID、UnionID 或其他个人信息。

## 验收

- 两条候选路线均可在真机离线完成"材料选择—铺贴拖动—节奏点按"三步并到达结果页。
- 候选帧动画在资源可用时循环播放；任一帧加载失败或资源缺失时，静态图和交互仍可用，用户无感知中断。
- 所有候选视觉区域（含帧动画）持续显示"候选视觉示意，尚待专业确认"。
- 首页、档案和结果页正确呈现轻量入口或完成标记，不扩大为新的互动页面。
- 既有学习报告、进度、收藏、提示、重试、退出、能力降级和匿名分析契约保持可用。
- npm test 全部通过，git diff --check 无输出；在开发者工具与至少一台真机检查触控阈值、帧动画播放与回退、首屏加载和三分钟演示流程。
