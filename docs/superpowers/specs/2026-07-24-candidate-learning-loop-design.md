# 候选内测学习闭环设计（第一期）

## 目标与范围

将当前候选内测小程序从一次性的三步骤体验，扩展为“档案学习 -> 互动体验 -> 学习报告 -> 本地进度回看”的闭环。

本期只使用候选示例文案和本地占位素材；不宣称未获专业确认的历史或工艺结论，不提交公开审核或正式发布。本期不新增 CloudBase 集合、云函数、函数权限、触发器或 Web 能力。

## 用户路径

1. 用户在档案页浏览两条候选路线的结构化条目。
2. 用户从条目进入既有三步骤互动体验。
3. 体验创建本地学习会话，并记录开始、步骤完成、提示、重试、完成或退出。
4. 完成后显示学习报告；用户可再次体验、查看对应档案或查看我的进度。
5. 我的进度页汇总路线完成次数、最近完成时间、总用时和最近一次步骤表现。
6. 活动页仅展示候选内测说明和已完成路线统计，不虚构公开活动。

## 页面职责

### 档案页

- 展示候选路线卡片：名称、候选标识、工艺阶段、学习目标、三步概览。
- 提供“开始体验”和“收藏”入口。
- 显示本地进度摘要；无记录时显示“尚未体验”。
- 条目详情以轻量展开或详情页呈现，具体布局由实现阶段沿用现有页面风格确定。

### 体验页

- 保留当前三步骤状态机和能力降级行为。
- 使用学习会话服务记录步骤表现，但学习记录失败不得阻断体验。
- 正常完成时生成报告并跳转结果页；退出时保存退出记录，不生成完成报告。

### 结果页

- 展示路线、完成时间、总用时、三步状态、每步提示和重试次数。
- 掌握状态仅使用“已完成”或“可再次练习”，不使用分数、排名或能力判断。
- 提供“再次体验”“查看档案”“查看我的进度”和返回首页入口。

### 我的进度页

- 新增或复用页面显示按路线汇总的本地进度，以及最近报告列表。
- 每条报告只显示候选路线、完成/退出状态、时间和脱敏学习统计。
- 收藏候选档案条目单独列出；无数据时显示明确空状态。

### 活动页

- 显示候选内测说明、已完成路线数量和继续体验入口。
- 不包含对外报名、公开活动承诺、真实地点或未经授权的活动素材。

## 本地数据与接口

新增一个本地优先的学习仓储服务。页面和控制器只能通过服务调用，不能直接依赖微信存储键。

接口：

- `startLearningSession(routeId, startedAt)`
- `recordStepOutcome(sessionId, stepId, outcome)`
- `completeLearningSession(sessionId, completedAt)`
- `exitLearningSession(sessionId, exitedAt)`
- `saveSessionReport(report)`
- `listSessionReports()`
- `getRouteProgress(routeId)`
- `toggleFavorite(itemId)`
- `listFavorites()`

记录字段仅限本地生成的会话标识、候选路线标识、事件时间、步骤标识、提示次数、重试次数、状态和用时。不得存储 OpenID、UnionID、手机号、昵称、头像、精确位置、设备唯一标识或任意自由文本。

服务必须提供明确的版本化数据结构和安全的空数据/损坏数据恢复；未来匿名云端同步只能替换服务内部实现，不能改变上述调用接口。

## 与现有埋点的关系

- 保持现有匿名埋点事件契约、事件名称、CloudBase 集合和云函数不变。
- 学习报告仅写入本地存储；不得把报告全文或新字段写入 `behavior_events`。
- 本地学习记录写入失败时，体验流程、既有事件埋点和结果页均应继续可用。

## 错误处理与隐私边界

- 缺少、损坏或过期的本地记录按空状态处理；不得抛出阻断页面渲染的异常。
- 仅接受配置中的两条候选路线和三个步骤标识。
- 收藏只支持候选档案条目；未知标识不得写入。
- 所有候选内容保持内部候选标识；不将其作为专业确认或公开内容展示。

## 验收标准

- 用户能从档案进入任一路线，完成三步骤后看到非评分学习报告。
- 报告准确显示总用时、步骤状态、提示和重试次数。
- 进度页在重启小程序后仍能显示本地完成记录和收藏。
- 退出体验会保存退出记录，但不会被计为完成。
- 本地存储损坏、不可用或写入失败时，体验不会被阻断。
- 自动化测试覆盖仓储数据校验、报告汇总、收藏切换、体验控制器集成和页面入口。
- 不新增 CloudBase 资源或真实身份字段，现有 `npm test` 保持通过。
