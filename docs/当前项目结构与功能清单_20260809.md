# 当前项目结构与功能清单

> 更新日期：2026-08-10\
> 当前对外主线：五步连续互动体验。\
> 内容边界：实际合作对象、传承人和城市尚未经过专业访谈确认；页面展示的是候选内容。

## 1. 当前产品定位

这是一个微信原生小程序候选原型。用户在同一张“箔面状态”上完成“做捻子 → 装家生 → 打箔 → 出具检查 → 切箔成叶”五步连续互动，并获得本地体验结果、知识回看和收藏记录。

页面不将项目认定为任何具体城市、传承人或认定等级。资料中的具体案例只作为明确标注的技术参照，不等同于本项目身份。

## 2. 对外页面与用户流程

`miniprogram/app.json` 注册以下六个正式页面：

```text
首页 → 五步互动体验 → 结果页
  ├─ 金箔志（知识卡、收藏）
  └─ 活动
结果页 → 我的进度
```

| 页面 | 目录 | 用户可见功能 |
|---|---|---|
| 首页 | `miniprogram/pages/home/` | 进入五步体验，打开金箔志或活动 |
| 工艺体验 | `miniprogram/pages/experience/` | 裁切、装箔、打箔、检查、成叶；提示、重试与新手辅助 |
| 结果页 | `miniprogram/pages/result/` | 箔面质量、学习报告、海报、再次体验和后续入口 |
| 金箔志 | `miniprogram/pages/archive/` | 候选知识卡、完成次数、收藏与开始体验 |
| 活动 | `miniprogram/pages/activity/` | 内测状态与返回首页 |
| 我的进度 | `miniprogram/pages/progress/` | 当前设备的收藏与学习报告 |

## 3. 五步体验

| 步骤 | 主要交互 |
|---|---|
| 做捻子 | 按住并水平拖动裁刀，稳定裁出金片 |
| 装家生 | 将金片拖至纸包中心，减速并停稳后松开 |
| 打箔 | 选择格点、蓄力并按节拍落锤，控制箔面风险 |
| 出具检查 | 移动检视灯探查箔面，可接受状态或定点返工一次 |
| 切箔成叶 | 连续拖动覆盖箔面，再保持不动完成收尾 |

## 4. 保留但未注册的实验代码

`pages/craft/`、`pages/foil-apply/`、`pages/foil-result/` 以及对应的工序数据和测试为“十二工序阅读 + 贴箔”实验分支。它们保留在仓库，供后续讨论和复用，但不在 `app.json` 注册，也没有首页入口。

如要再次启用该分支，必须先完成内容审核、明确其与五步体验的关系，并重新设计统一的数据与结果闭环。
