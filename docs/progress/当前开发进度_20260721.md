## 第 7 项关键决策

- 经项目负责人确认，`behavior_events` 客户端读取、创建、更新和删除全部关闭，事件统一通过 `submitBehaviorEvent` 云函数提交。
- CloudBase 环境必须专用于该微信小程序，不得与 Web SDK、其他客户端认证入口、HTTP/API 网关或额外触发器混用。
- 云函数从可信运行时上下文读取 `OPENID` 与 `APPID`；原始身份标识不得记录、返回或持久化。
- 相同 `eventId` 与相同规范化载荷只确认一次；相同 ID 的不同载荷拒绝覆盖。
- 路线确认在单个事务中完成内容复读、现有路线校验、正式文案替换和匿名审批留痕。
- `content_items.confirmedRoute` 必须提供经审核且不含“候选示意／内部测试”等占位标记的正式路线内容，否则审批失败关闭。
